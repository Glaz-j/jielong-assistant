# Windows 安装版 1.1.0

2026-11-04。新增 Setup.exe、桌面/开始菜单快捷方式、卸载入口、四步首次配置和可选开机自启。字段与自动填写流程保持原有四项资料范围。

## 用户操作

1. 下载 `JielongAssistant-Setup-1.1.0.exe`，双击按向导安装。
2. 打开桌面「接龙助手」：填写资料 → 本人官网登录 → 选择微信群 → 启动监听并完成设置。
3. 需要自动启动时，勾选「登录 Windows 后自动在后台启动」，保存。此选项默认关闭。

安装在当前用户目录，运行环境已打包，不需要开发工具。自启时不打开网页；微信稍后就绪时重试之前明确开启的监听。停止监听后不自动恢复。便携 ZIP 保留，但不提供开机自启。

## 验证边界

- 已测试自启注册项和它实际执行的启动命令，未进行整机重启/注销再登录测试。
- 本轮 Windows 安装/升级采用静默安装模式；首次配置页面由真实浏览器的隔离测试覆盖，没有让新用户重新扫码登录。安装后恢复了现有本人登录态的真实监听。
- 本轮未新增官网报名样本；1.0.0 的两次真实群卡片计时仍见 [原验收记录](../delivery/验收记录.md)，不能据此宣称所有活动都保证 10 秒内完成。
- Setup.exe 目前未数字签名；其他机器的系统或企业策略可能阻止执行。没有关闭系统安全保护。
- 卸载保留 `%LOCALAPPDATA%\JielongAssistant`；不会删除个人资料、登录或历史报名记录。

## 构建

运行 `python3 delivery/build.py`，再运行 `python3 delivery/build-installer.py`。需要 NSIS `makensis`；本次编译器 3.13。构建输出目录 `release/` 不进入源码仓库。

安装器采用 [NSIS 当前用户权限模式](https://nsis.sourceforge.io/Docs/Chapter4.html)，使用当前用户快捷方式/注册项；通过本地认证退出 API 等待在途任务，不强杀其他进程。卸载按构建白名单逐文件移除，不递归清空任意安装目录。
