# 静默后台版本（2026-11-04 开发验证）

本版本使用固定 Node.js 程序和 Playwright 无窗口浏览器。运行时不调用 Computer Use、截图、全局鼠标键盘或窗口激活接口；不操作用户日常浏览器。登录失效只写错误记录，不打开登录窗口。

**真实微信/QQ 卡片消息流尚未接入。** 当前只接受明确标记为 `simulation` 的文件事件，用于独立验收后台填表。它不能替代真实群消息端到端验收。旧远程 OCR/鼠标版已停用，并由 `silent-mode.flag` 阻止重新启动。

## 启停

Windows 依赖已安装 Node.js 和 Microsoft Edge。解压测试包后双击 `start-silent.vbs`，以隐藏窗口启动服务。双击 `stop-silent.vbs` 停止接收新任务，等待正在提交的任务结束后退出。两者均无提示框。

跨平台命令行为 `node silent-worker.mjs <数据目录>`。开发环境需已有 Playwright 浏览器；Windows 默认使用本机 Edge，无需下载另一套浏览器。

`silent-data/config.json` 只提供群名、四项固定资料、测试活动白名单和本次已同意的《保存个人信息授权》。未知授权、未知必填字段、未完整匹配四字段、登录失效都停止，不弹窗。配置中仍保留测试活动白名单，未开启任意真实业务活动自动报名。

`status.json` 表示服务是否就绪；`results/*.json` 和 `jobs.json` 表示任务结果。模拟文件原子写入 `inbox/` 后处理并移至 `accepted/`。可使用：

```sh
node emit-silent.mjs silent-data 文件传输助手 https://i.jielong.com/f/已获准测试活动编号
```

启动前存在 `stop.flag` 时命令行服务会停止；VBS 启动器会清除此标记。不要手动删除正在运行的服务锁。

## 防重复和验收边界

官网同一活动的公开短链接可能变化。程序从当前官网页面的正常响应读取稳定 `ThreadId`，按它持久化提交记录并阻止并发重复。提交结果不明时不自动重试。服务锁阻止同一数据目录重复启动。

测试覆盖实际无窗口浏览器填写与提交、并行活动、错误群、未接入的真实消息源拒绝、登录失效、短链接变化后的重复阻止、持久化记录及时间口径。模拟网页测试不能证明网络和平台在所有情况下均可在 10 秒内响应。

`auth.json` 是私人官网登录会话，只能在本人的开发和远程机器之间使用；不得上传仓库或公开分享测试包。数据目录、认证文件、测试包均已加入忽略规则。远程会话是否接受迁移登录态仍需实际验证；失效时服务只记录错误，不自动弹出认证界面。
